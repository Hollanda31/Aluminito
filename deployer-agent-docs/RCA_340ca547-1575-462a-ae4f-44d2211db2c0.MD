# RCA — Deploy run 340ca547-1575-462a-ae4f-44d2211db2c0 (aluminito-esquadrias)

## Summary
The redeploy failed at the `build_image` step. The frontend compile (`craco build`) aborted because the React app's entry file `frontend/public/index.html` does not exist. This is a **source-level problem**: the frontend's `src/` and `public/` directories are missing from the app source entirely.

## Evidence
### Cloud Build log (step #2 docker-build, frontend-build 12/13)
```
#51 55.96 $ craco build
#51 57.12 Could not find a required file.
#51 57.12   Name: index.html
#51 57.12   Searched in: /app/public
#51 57.15 error Command failed with exit code 1.
```
An earlier line in the same build also showed the `.env` rewrite step warning `sed: /app/.env: No such file or directory` — consistent with an incomplete frontend checkout.

### Verified in sandbox (eph pod, pulled source for this run at /app/scratch)
`ls -la /app/scratch/frontend` returns ONLY config files:
```
.gitignore  README.md  components.json  craco.config.js
jsconfig.json  package.json  postcss.config.js  tailwind.config.js
```
- `ls /app/scratch/frontend/public` → **No such file or directory**
- `ls /app/scratch/frontend/src`    → **No such file or directory**
- `find /app/scratch/frontend -name index.html` → **no results**
- `frontend/.gitignore` does NOT list `src` or `public`, so this is not a gitignore artifact — the files are genuinely absent from the source.

The backend directory (`/app/scratch/backend`) is present and the backend-build stage completed; only the frontend is broken.

## Root cause
The entire React application source — `frontend/src/` and `frontend/public/` (including `public/index.html`) — is missing from the app source in the preview environment. Previous runs (e.g. 0c0af6e3, succeeded 2026-11-11) built fine, so these directories were deleted/lost after that successful run.

## Fix (Code — E1/main agent)
Restore the frontend source in the preview environment:
- `frontend/public/index.html` (CRA entry HTML) and the rest of `frontend/public/`
- `frontend/src/` (the React application code: index.js/App.js and components)

Once restored, redeploy. No manifest or platform change is required; the Dockerfile and build config are correct and the backend builds successfully.

## Not the cause
- Not a manifest/template issue (manifests unchanged; backend-build succeeded with the same Dockerfile).
- Not a dependency resolution failure (`yarn install` completed — "success Saved lockfile.").
- Not a secrets/tier/DB issue.
